# Code of conduct

hoocode is built by volunteers, for people who spend their days in a terminal. Keep it
a place where anyone can ask a question, file a bug or send a first pull request.

## Expected

- **Be kind.** Many contributors are writing in a second language, or opening their
  first pull request.
- **Assume good faith.** A bug report that sounds blunt was probably written in a hurry,
  by someone whose work just broke.
- **Be specific.** "hoocode 0.1.41, macOS 15, Ghostty, `/resume` shows an empty list"
  helps. "Doesn't work" doesn't.
- **Respect decisions on scope.** The core stays small on purpose, and a lot of good
  ideas belong in a skill, a plugin or an MCP server instead. A "not in core" is not a
  rejection of you.
- **Own your contribution.** Using a coding agent is fine; you should still be able to
  explain your change.

## Not accepted

- Insults, harassment, slurs, sexualised language or imagery, or personal attacks, in
  issues, pull requests, reviews or anywhere else in the project.
- Publishing other people's private information, including keys, tokens, session files
  or anything that identifies someone's machine or employer.
- Mass-produced, low-effort issues or pull requests, from a person or an automated
  tool.
- Spam, or passing off someone else's work as your own.

## Enforcement

Maintainers may edit, hide or remove content, and block accounts that break these
rules, with a short explanation. To report something, open an issue, or if it is
private, message [@kolisachint on X](https://x.com/kolisachint). Reports are read by
the maintainer and handled within a few days.

This is a short, plain-language code adapted in spirit from the
[Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
