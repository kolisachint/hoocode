# hoocode-ai-oauth-openai-codex

OpenAI Codex OAuth login (ChatGPT Plus/Pro subscription): authorization code + PKCE with a
local callback server on port 1455 racing an optional pasted code. The credentials carry
the `accountId` claim of the access token.

Part of the [hoocode](https://github.com/kolisachint/hoocode) Rust workspace.
