# hoocode-app-server-protocol

Wire types for `hoocode app-server`: the subset of the Codex app-server
protocol that hoocode serves, written for this project (MIT). Nothing here is
copied from Codex; field names follow its wire format so Codex clients can
connect. Design: `docs/design/app-server.md`.

Part of the [hoocode](https://github.com/kolisachint/hoocode) Rust workspace.
