# hoocode-code-tools

Coding tools for the hoocode coding agent

Part of the [hoocode](https://github.com/kolisachint/hoocode) Rust workspace.

The default tool bundle of the coding agent: `read`, `edit` and `write` from
`hoocode-code-tools-fs`, `bash` from `hoocode-code-tool-bash` and `CodeSearch` from
`hoocode-code-tool-search`, plus the file finder, light mode and permission helpers.
